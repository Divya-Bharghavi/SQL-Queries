# SQL Workspace – Data Analysis and Table Management

This project contains SQL scripts demonstrating data querying, filtering, and database schema management.  
It includes examples of `SELECT`, `WHERE`, `ORDER BY`, `CASE`, `BETWEEN`, and DDL operations such as creating, modifying, and altering tables.

### Key Features
- Data filtering and sorting using `WHERE`, `ORDER BY`, and `LIMIT`
- Conditional logic with `CASE WHEN`
- Creating and linking tables using `FOREIGN KEY`
- Altering schema using `ALTER TABLE` (add, modify, drop columns)
- Applying constraints and ensuring data integrity

### How to Run
1. Open any SQL environment (MySQL Workbench, VS Code SQL extension, etc.).
2. Copy and paste the queries from `database_queries.sql`.
3. Execute them one by one to view results.
